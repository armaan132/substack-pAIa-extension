# The Ideology Mapping Project

A possible follow-up project of the substack-paia could be an ideology mapping project.

Either for individual substackers or groups of substackers, one could map out their ideology. This will not be mainly a SWE project as mapping ideologies will require good faith conversations between humans. It will be important that each ideology is mapped in the language and with the arguments of the holders of the ideology. Each "ideologue" should be able to accept the description. 

This is related to the idea of strongman arguments and also to the idea of adversarial collaboration as studied by Kelvin McQueen. There may also be connections to argumentation theory. But the aim is not scientific discourse but discourse about politics in the public sphere.

Currently, I am thinking about it as follows: Every ideology is a "false ideology" from some point of view. Some ideologies may be useful and serve a purpose at some point in time, from some point of view.

Next to mapping ideologies, this project will also have to map values. Values define the point of view. In the process of mapping a particular ideology, or rather the ideology of a particular person (or group of persons), 

- How to define groups of persons? Can one do this using unsupervised machine learning?
- How much do LLMs know about ideologies? Can one extract ideologies from LLMs? Can one use the characterizations of ideologies made by LLMs in order to map ideologies?

This project will be an interdisciplinary project involving experts in political science, philosophy, and computer science.
